# Historial de cambios

Las fechas de publicación y los archivos de cada versión están en [Releases](https://github.com/ecupe/ECUShippingSimulator-Demo/releases).

## Pre-alpha 0.1

Build: **17 de octubre de 2026**.

- Primera demo de Windows para probar el recorrido de un envío.
- Pedidos desde el teléfono y productos con ubicación en el almacén.
- Embalaje, etiqueta y entrega en USPS, UPS o FedEx.
- Menú de inicio con logo, opciones, créditos y pausa.
- Ayuda emergente y HUD reducido.
- Teléfono que sube verticalmente al presionar Tab.
- Personaje y pies visibles al mirar hacia abajo.

La fecha de esta build y la fecha en que se publica en GitHub pueden ser distintas. Cada actualización se publica como una nueva versión y conserva su propia descarga.
